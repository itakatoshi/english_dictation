# YouTube Dictation Trainer v0.4.0

YouTube の英語字幕トラックを使って、動画と正確に同期したディクテーション練習を行う Chrome 拡張です。

## v0.4.0 の主な変更

- 問題UIを **YouTube動画の右側（おすすめ欄の先頭）** に移動
- 画面上の字幕DOMから時刻を推定する方式を廃止
- YouTubeの **字幕トラック（timed text）に含まれる開始/終了タイムコード** を使用
- 字幕区間の終了時刻で動画を自動停止し、その区間の英文を問題化
- 「聞き直す」は同じ字幕区間の開始時刻から終了時刻までを再生
- 全文モードでは単語数・文字数の下線ガイドを維持
- 入力欄と答え表示欄は同じ場所
- YouTube標準字幕は答えが見えないよう拡張ON中だけ非表示
- YouTube側で字幕を表示ONにしておく必要はありません

## 使い方

1. `chrome://extensions/` を開く
2. デベロッパーモードをON
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選ぶ
4. 英語字幕トラックのある YouTube 動画を開く
5. 拡張をON
6. 右側に `同期済み: English / xx文` と表示されたら再生する
7. 1つの練習区間が終わると自動停止し、右側で入力する

## 同期方式

v0.3.x までは、画面上に表示された字幕文字を MutationObserver で監視し、その瞬間の video.currentTime から時刻を推定していました。この方式は字幕のローリング表示やDOM更新遅延により、英文と音声がずれることがありました。

v0.4.0 では動画ページから字幕トラックURLを取得し、`json3` 字幕に含まれる `tStartMs` / `dDurationMs` を直接使用します。そのためReplayと問題文は同じ字幕区間を参照します。

## 注意

- 英語字幕トラックが存在しない動画では使用できません。
- YouTubeの仕様変更により字幕トラック取得方法が変更された場合は追従が必要です。
- 自動生成字幕では句読点が少ないことがあるため、複数の字幕cueを約8秒以内の練習単位にまとめる場合があります。ただし開始・終了は元字幕cueのタイムコードを使います。
