# YouTube Dictation Trainer v0.5.0

YouTube の英語字幕トラックを使って、動画と正確に同期したディクテーション練習を行う Chrome 拡張です。

## v0.5.0 の主な変更

- **字幕取得の修正**: YouTube の Web 版字幕URL（`exp=xpe`）が PO トークンなしでは空の本文を返すようになり、v0.4.0 は字幕を読み込めなくなっていました。Innertube の ANDROID / IOS クライアント経由でトラックを取得し、失敗時は従来の方式に戻ります。
- **単語単位の採点**: 位置の比較をやめ、編集距離で単語を対応付けます。1語抜けても、それ以降が全部「不正解」にはなりません。
  - 聞き間違い（赤）・スペルミス（黄）・抜け（紫）・余分な語（取り消し線）を色分け表示
  - 正答率（%）を表示
  - `gonna` = `going to`、`3` = `three`、`colour` = `color`、`well-known` = `well known` などの表記ゆれは正解扱い
- **停止精度の向上**: `timeupdate`（約250ms間隔）に加えて再生中は毎フレーム判定するため、次の文の頭が聞こえにくくなりました。自動生成字幕で重なっているcueは次のcueの開始時刻で切ります。
- **穴埋めモードの修正**: 正解が表示されないバグを修正。空欄の文字数を表示し、答え合わせ後は空欄に正解を埋めて表示します。
- **「答えを見る」**: 従来の「パス」は答えを見せずに次へ進んでいました。答えを表示してから「次へ」で進むように変更。
- **⏮ 前の文**、**キーボード操作**（下表）
- **復習リスト**: 間違えた文を記録し、ポップアップから動画のその位置へジャンプできます。累計正答率も表示。
- **1問の長さ**: 短め（字幕1行ずつ）/ 標準 / 長め。句読点のない歌詞や自動字幕では「短め」が向いています。
- 聞き直し速度に 0.5x を追加。聞き直し後は元の再生速度に戻します（以前は常に1.0xへリセット）。
- YouTube のダークテーマに対応。シアターモード等で右カラムが無いときはパネルを浮かせて表示。

## 使い方

1. `chrome://extensions/` を開く
2. デベロッパーモードをON
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選ぶ
4. 英語字幕トラックのある YouTube 動画を開く
5. 拡張をON
6. 右側に `同期済み: English / xx文` と表示されたら再生する
7. 1つの練習区間が終わると自動停止し、右側で入力する

YouTube 側で字幕を ON にする必要はありません（標準字幕は答えが見えないよう拡張ON中は非表示になります）。

### キーボード

| キー | 動作 |
| --- | --- |
| Enter | 答え合わせ / 次へ |
| Ctrl+Space | この文を聞き直す |
| Alt+H | 1文字ヒント |
| Alt+S | 答えを見る |
| Alt+B | 前の文に戻る |

## 開発

```bash
npm install        # DOMスモークテスト用の jsdom（任意）
./run.sh test      # 構文チェック + 単体テスト + DOMスモークテスト
./run.sh check     # 実際のYouTubeから字幕を取得できるか確認（ネットワーク必要）
./run.sh zip       # dist/ に配布用zipを作成
./run.sh all       # 上記すべて
```

- `lib.js` — DOM に依存しない処理（採点・字幕の整形・区間分割）。Node のテストからも読み込みます。
- `content.js` — YouTube ページ上のパネル、再生制御、字幕の取得
- `popup.*` — 設定と復習リスト

## 同期方式

動画の字幕トラック（`json3`）に含まれる `tStartMs` / `dDurationMs` を直接使用します。問題文と「聞き直す」は同じ字幕区間を参照します。自動生成字幕では句読点が少ないため、複数cueを「1問の長さ」の上限までまとめます。開始・終了は元のcueのタイムコードです。

## 注意

- 英語字幕トラックが存在しない動画では使用できません。
- 字幕取得は YouTube の非公開API（Innertube）に依存しています。仕様変更で取得できなくなった場合は `content.js` の `INNERTUBE_CLIENTS` のクライアントバージョンを更新してください（`./run.sh check` で確認できます）。
